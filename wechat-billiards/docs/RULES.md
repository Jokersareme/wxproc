# 对局规则

## 黑八

- 16 球，开球后台面开放；开球落袋不立即分组，开球后的合法落袋确定全色/花色。
- 开球无落袋时，至少四颗目标球碰库为合法开球。
- 分组后先碰本组球；本组清完后先碰黑八。母球未碰目标球、首碰错误、母球落袋、碰球后无落袋也无碰库均为犯规。
- 合法落袋继续击球，否则交换。犯规后对手可在合法台面区域摆自由球。
- 开球黑八落袋会重摆黑八；非开球提前或犯规打进黑八判负，清完本组后合法打进黑八获胜。

## 九球

- 10 球，每杆先碰当前最低号目标球，组合球允许。
- 开球无落袋时至少四颗目标球碰库；其他合法性与黑八的碰库/落袋要求一致。
- 合法落袋继续击球；合法打进九号球获胜。
- 犯规后对手获得自由球，九号球若同时落袋则重摆，不判胜。

## 斯诺克

- 标准 15 红球和 6 彩球。红球与彩球交替，彩球在红球阶段落袋后复位。
- 红球清完后按黄、绿、棕、蓝、粉、黑顺序清彩，此阶段彩球不复位。
- 犯规罚分取 4 分及所涉球值中的适用较高值，最高 7 分；彩球犯规落袋复位，红球不复位。
- 母球落袋后对方在 D 区摆球。几何检测判定被斯诺克时可提名彩球为自由球；自动检测不能替代专业裁判。
- 最后黑球后比分高者获胜；同分重摆黑球并在 D 区摆母球决胜。
- 本版不自动执行裁判裁量的 miss、警告、重新摆回原位和争球程序，游戏内也有相同边界说明。

物理使用上游固定步长模型。瞄准线只是视觉辅助，所有落袋、犯规、得分和胜负以服务器核心计算为准。

## 道具模式

- 仅双人房；建房时选择玩法（黑八/九球/斯诺克）和手牌数 0–6，默认 3；0 表示关闭卡牌。
- 双方开局各发 N 张明牌；每回合最多使用 1 张，只能在自己回合、击球前使用。使用卡牌不消耗击球权。
- 卡牌效果写入权威快照；击球仍由同一物理核心模拟。客户端只负责选择目标和播放动画。
- 持续效果在对应时机过期：本杆、对手下一杆、对手下一回合或本局。客户端以服务端快照为准。
- 无效目标、对手无手牌、没有可移除效果时，卡牌退回，不消耗本回合。
- 单人练习默认启用卡牌，发牌时过滤需要对手的牌（沉默、护盾、换手、识破、冻结、偷牌、复制）；菜单可改手牌数并立即重新发牌。

| 卡牌 | 稀有度 | 效果 |
| --- | --- | --- |
| 鹰眼 | 普通 | 本杆预测线 +2 档 |
| 重炮 | 普通 | 本杆力度上限 +20% |
| 轻推 | 普通 | 本杆力度 ×0.65，预测 +1 档 |
| 强塞 | 普通 | 本杆杆法上限 0.45 → 0.65 |
| 沉默 | 普通 | 对手下回合不能出牌 |
| 护盾 | 稀有 | 本局抵消一次犯规的罚分/自由球 |
| 移形换位 | 稀有 | 移动一颗非关键球最多 1.5R |
| 换手 | 稀有 | 与对手随机交换一张手牌 |
| 识破 | 稀有 | 移除对手一个持续效果 |
| 弹性增强 | 稀有 | 本杆库边恢复 ×1.15 |
| 奖金球 | 稀有 | 本杆每次合法进球 +1 分（九球/斯诺克） |
| 复制 | 稀有 | 复制对手最后使用的一张牌 |
| 冻结 | 史诗 | 对手下一杆力度 ×0.6、无杆法 |
| 偷天换日 | 史诗 | 随机夺走对手一张手牌 |
| 续命 | 史诗 | 本局第一次黑八误进不判负（黑八） |
| 双倍 | 史诗 | 本杆合法得分 ×2（斯诺克） |
| 号令 | 稀有 | 指定本杆首碰球（九球） |
| 红球雨 | 史诗 | 放回最多 2 颗已落袋红球（斯诺克红球阶段） |

关键球不能移动或偷走：母球、黑八、九号球、斯诺克黑球。移球不能进袋、重叠或越界。

## 三人斯诺克

- 仅斯诺克；固定 3 个座位，按 `0 → 1 → 2 → 0` 轮转，自动跳过已退出玩家。
- 第一局座位 0 开球，之后每局按座位轮换开球。第 2 人加入后先进行两人热身；第 3 人加入后 3 秒倒计时自动开局。
- 犯规罚分记给下一位仍在场的玩家，不重复记给另外两家；自由球给新的当前玩家。
- 合法进球继续击球；未进球或犯规轮到下一位仍在场的玩家。
- 本局结束时按总分、单杆最高分、进球总数依次排名；仍相同显示并列名次。`winner` 只在唯一第一时存在。
- 中途退出标记为“已退出”，跳过其回合；只剩 1 人时本局立即结束。房主退出后由座位最小的仍在场玩家接任房主。
- 断线保留座位并等待重连；轮到离线玩家时其他玩家等待。三人房不做自动托管、观战、三人黑八/九球或道具模式。
- 三人房“再来一局”需要房间内仍在线且未退出的玩家确认；人数不足时回到热身/试玩等待新玩家。
