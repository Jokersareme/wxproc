## 3. 已实现功能

- 黑八、九球、15 红球斯诺克和单人练习。
- 固定 `1/512` 秒物理步长、犯规、自由球、重摆、计分、胜负及确定性快照哈希。
- Three.js 球桌、球号和花色、球杆、瞄准线、击球动画、触摸力度及杆法。
- 真实贯穿袋口、袋腔、皮革袋唇、分段库边和圆角袋角。
- 默认 2D 俯视，可经左上角菜单切换 3D；菜单同时收纳音效和退出，弹窗遮罩阻止误触台面。
- 横屏 2D 球台长边水平，独立大视口避开顶部和两侧控件；击球按钮位于右侧微调滑轮下方。
- 左侧竖向力度条、右侧竖向瞄准微调滑轮；单击台面直接瞄准，拖动时方向跟随手指。
- 左下小杆法按钮弹出击球点调整窗，白点跟随手指，提交物理输入时修正 X/Y 方向；当次击球保留杆法，击球后及新开局自动归中。
- 首球碰撞方向预测线改为 0–5 六档：0 关闭，1–5 档按最大值的五等分递增，5 档为横向球台长度的 1/3；保留原瞄准线，仅显示母球切线和首个被碰球法线。
- 房间预测线档位经协议校验、双端广播和 CloudBase 持久化，兼容旧房间，重连及再来一局保持；单机练习可在菜单即时调整并保留偏好，联机只读房间设置。
- 统一物理手感：滚动摩擦 `0.009`、滑动摩擦 `0.15`、撞库恢复 `0.72`、最大杆速为原值 `0.72`（先降至 `0.82`，再根据手感反馈继续下调），双端共用调参模块。
- 球体按实际位移滚动，静止球不再自转。
- 自由球可连续拖动白球调整，权威快照保留重摆资格并兼容旧快照，实际击球后清除。
- 二人好友房、六位房间码、随机邀请令牌、准备、认输、双方再来一局。
- 服务端权威击球、幂等重试、断线座位保留、重连和 CloudBase 房间持久化。
- 微信登录、云托管 WebSocket、分享邀请、存储、振动和合成击球音效。
- GPL-3.0 许可证、第三方声明和固定版本公开源码链接。

斯诺克自动 miss/裁判复位没有实现，文档和游戏内需要继续明确这一边界。项目不是腾讯产品，不包含腾讯商标、美术、音频或私有协议，不应宣称与腾讯桌球逐像素或全部运营功能一致。
