# 隐私与数据说明（发布前按实际运营信息补全）

- 客户端通过 `wx.login` 获取临时 code，服务端用微信 `code2Session` 验证。AppSecret 仅保存在云托管环境变量中。
- 服务端不保存原始 openid，而是保存其 SHA-256 截断标识。会话令牌随机生成、默认七天过期，保存在客户端本地和服务端内存中。
- 房间保存昵称、哈希用户标识、玩法、对局快照、击球事件、幂等记录、邀请令牌和更新时间，用于联机、重连和回放。分享接收者会获得该房间邀请令牌，请勿公开转发给不相关的人。
- 日志不得记录 AppSecret、session_key、登录 code 或会话令牌。生产监控接入后需另行审查日志字段。
- 本地浏览器预览使用随机开发标识，不上传微信身份信息。

发布者需要补充主体名称、联系方式、数据保存期限、删除渠道和云服务商信息，并在微信公众平台配置与实际一致的隐私政策。长期无人房间的清理任务尚未配置，上线前应确定期限并实现定时清理。
